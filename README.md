# 词间 · 英语二基础补词

在线使用：https://louise-zqf.github.io/word-garden-english-two/

GitHub Pages 从 main 分支的 /docs 目录自动发布，更新该目录并推送即可更新网站。

私人背词网站，界面参考大观园学习区的浅灰背景、白色卡片、蓝色操作按钮和侧边导航。

内置669个常见基础表达与派生词候选、102个近义/词根/同源/主题分组，组间乱序、组内联想。候选库未与两本扇贝词书做精确差集；通过“排除已背词”粘贴原词表即可准确排除，排除结果可恢复。

鼠标点击认识/不认识，键盘←不认识、→认识；空格查看释义，S切换每日重点，Esc移除简单词，Z撤销。无论选择认识还是不认识，都先展示释义，再按→或空格确认继续。选择认识后，发现意思记错可点“记错了，改为不认识”或按←；Z可撤销上一步，错误判断不会直接跳到下一词。

重点词按北京时间每天进入复习队列，直到手动取消。普通词认识后采用1/3/7/14/30天间隔，错词本轮反复出现，直到连续两次在未看释义时答对；再次答错会清零连续次数，次日仍要复习。同一天反复练习不会把长期复习间隔拉长；提前查看释义后选择认识也不会计为回忆答对。每日新词量在设置中可调，到期复习词与重点词不占新词额度。

“批量加词”接受逐行、逗号分隔、中英混排与英文段落；带中文的短语可整条录入，离线词典尽可能补全释义，导入前可以改释义、去重和勾选。自定义词可以手动放入已有分组。

进度保存在当前浏览器，不提供自动跨设备同步。“设置与备份”可以导出完整JSON备份、恢复备份、导出TXT词表。清理浏览器网站数据前请保存备份。

本地使用：用浏览器打开docs/index.html；也可在docs目录运行 `python3 -m http.server 8765` 后访问 http://localhost:8765 。纯静态，无运行依赖，词条与词典都随网站提供。浏览器语音朗读依赖系统语音支持。

词库来源：NETEMVocabulary（https://github.com/exam-data/NETEMVocabulary，CC BY-NC-SA 4.0）与KyleBing/english-vocabulary（https://github.com/KyleBing/english-vocabulary，BSD-3-Clause）；人工选择、分组、清理释义并补充常见派生词。未将混合考试语料的词频表述为英语二独立考频，未宣称是2027官方考纲。

验证学习逻辑：`node --test tests/core.test.cjs`。

背诵卡片在回忆前不显示分组名称；选择认识或不认识后，再展开释义与联想辨析。Esc直接移除当前简单词，可用Z撤销；弹窗打开时Esc仅关闭弹窗。
